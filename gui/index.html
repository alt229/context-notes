        Settings

        Anthropic API key

        Get one at console.anthropic.com. API use is billed to your Anthropic account, separately from a Claude subscription.

        API credit

        Anthropic doesn't let programs ask for your balance. So this counts down from the figure you give, as notes are written, and it's an estimate: it leaves out anything else spent on the same account. Type the console's figure in again after you add credit.

        This week

          The plan figures come from Claude Code's status line and cover everything on your plan (chat as well), so they only update while Claude Code is open here. Sessions used elsewhere are in the percentages but not in the count.

          OpenSubtitles.com

          Optional. Used to find subtitles for videos that have none. You need a free account and an API key from opensubtitles.com/consumers.

          VLC extension

          Loads the notes when you play a video in VLC, with a checkbox for each kind of note.
