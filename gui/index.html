              Settings

              Claude

              Where the notes are written. On your Claude plan (Pro or Max), Claude Code writes them in the background, with no API credits; it needs to be installed and signed in on this computer.

              Up to
              $a run
              A run is one press of Write the notes: every film and step in it.

              Defaults for every run

              The app and the Terminal scripts both start from these. A film that already has notes keeps its own look and audience; these apply to new notes and to new films.

              Starting folder:

              Anthropic API key

              Get one at console.anthropic.com. API use is billed to your Anthropic account, separately from a Claude subscription.

              API credit

              Anthropic doesn't let programs ask for your balance. So this counts down from the figure you give, as notes are written, and it's an estimate: it leaves out anything else spent on the same account. Type the console's figure in again after you add credit.

              This week

                The plan figures come from Claude Code: its status line while it's open here, and every request this app sends on your plan. They cover everything on your plan (chat as well). Click the Plan meter at the top for a fresh reading (one tiny request, no API credits). Sessions used elsewhere are in the percentages but not in the count.

                OpenSubtitles.com

                Optional. Used to find subtitles for videos that have none. You need a free account and an API key from opensubtitles.com/consumers.

                VLC extension

                Loads the notes when you play a video in VLC, with a checkbox for each kind of note.
