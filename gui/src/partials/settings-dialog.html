Claude

Saved as soon as you choose. The same models are used either way.

This server is already signed in another way, for example through a shared sign-in folder. You can still paste a token below; if you do, the app uses it instead.

Sign in

  1. On any computer that has Claude Code, run claude setup-token in Terminal.
  2. Sign in in the browser window it opens.
  3. Copy the token it prints and paste it here.

The token is kept on the server, in a file only the app can read. Saving this box empty removes it, which signs the app out.

Get one at console.anthropic.com. API use is billed to your Anthropic account, separately from a Claude subscription.

OpenSubtitles.com

Optional. Used to find subtitles for videos that have none. You need a free account and an API key from opensubtitles.com/consumers. Their service wants both the API key and your username and password, so fill in all three.

These are kept in a file on the server, readable only by the app.

VLC extension

Loads the notes when you play a video in VLC, with a checkbox for each kind of note.

Download the VLC extension

Put the file in VLC's extensions folder on your own computer:

macOS~/Library/Application Support/org.videolan.vlc/lua/extensions/
Linux~/.local/share/vlc/lua/extensions/
Windows%APPDATA%\vlc\lua\extensions\

Then restart VLC and choose VLC → Extensions → Context Notes.
